# Optional reference examples

This folder contains the optional GUI tools `set_swing` and `mute_track`, plus
default-tempo song creation. `set_tempo` is intentionally absent: the instructor
will provide it during the workshop. Students add it in `workshop/starter/`.

From the repository root, add `--server workshop/solutions/mcp_server_solution.py`
to `workshop_client.py` to inspect these optional examples.
